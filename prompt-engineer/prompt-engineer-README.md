# prompt-engineer

Master prompt engineering skill for every major AI system — image generators, video AI,
audio/music AI, LLMs, chatbots, and code AI.

## What It Does

Drop this skill into a Claude Project and Claude will generate perfectly structured prompts
for any AI tool. Each model gets its own optimized format because they all respond differently —
generic prompts get generic results, model-native prompts unlock peak performance.

## Triggers On

- "Write me a prompt for..."
- "How do I get better results from X"
- "Generate an image / video of..."
- "Improve this prompt"
- "Why isn't my prompt working"
- "Make [AI] do [thing]"
