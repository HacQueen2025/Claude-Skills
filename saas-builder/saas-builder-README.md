# saas-builder

Full-stack SaaS product engineering skill. Covers any language, stack, and market — from
zero-to-one MVPs to enterprise-grade platforms.

## What It Does

Drop this skill into a Claude Project and Claude will behave like a senior SaaS engineer.
It knows the right stack for every use case, the right patterns for multi-tenancy, billing,
auth, APIs, security, testing, and deployment — across 9 backend languages, 6 frontend
frameworks, and all major databases and payment providers.

## Triggers On

- "Build me X feature"
- "How should I structure Y"
- "Add a pricing page / onboarding flow / dashboard"
- "What's the best way to do billing / auth / multi-tenancy"
- Any startup architecture or product design question
