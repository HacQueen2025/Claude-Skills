# content-pipeline

Universal content scripting skill. Produces tight, platform-specific scripts for any
video or audio format, across any topic.

## What It Does

Drop this skill into a Claude Project and Claude will write properly structured scripts
instead of generic outlines. Every format has its own template — YouTube long-form is
structured differently from a Short, a podcast differently from an online course.
Every topic has its own writing guide.

## Triggers On

- "Write a script for..."
- "Plan a video about..."
- "Make a YouTube video on..."
- "Write a podcast episode about..."
- "Create an explainer for..."
- Any content strategy or scripting request

## Format Coverage

| Format | Best For |
|---|---|
| YouTube Long-Form (8–20 min) | Deep dives, tutorials, documentaries, storytelling |
| YouTube Short / TikTok / Reel (15–90s) | Quick facts, clips, trending content |
| Podcast / Audio-Only (20–60 min) | Interviews, opinion shows, narrative audio |
| Educational Explainer Animation (2–8 min) | Math, science, concepts with visual structure |
| Documentary / Narrative History (10–30 min) | Historical events, biographies, investigations |
| Online Course / Lecture (per lesson) | Structured learning with objectives and checkpoints |
| Ad / Promo Video (15–90s) | Product demos, brand films, conversion content |

## Topic Writing Guides

- **Science & Math** — application-first, formula after why, visual analogies
- **History** — specific names/dates, past-to-present connection, narrative arc
- **Economics & Finance** — personal stakes, simple analogies, data + interpretation
- **Philosophy** — concrete dilemma first, thought experiments, open endings
- **Technology / AI** — avoid hype, analogy-first, include limitations
